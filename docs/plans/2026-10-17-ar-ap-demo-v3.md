# AR & AP Demo V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thu hẹp và hoàn thiện dứt điểm 2 luồng nghiệp vụ cốt lõi (AR: Nghiệm thu 200tr -> Hóa đơn VAT 10% 220tr -> Thu tiền 220tr -> Công nợ về 0; AP: Hóa đơn Cloud AWS 250tr gross -> FCT 25tr [12.5tr VAT + 12.5tr TNDN] -> Duyệt 3 cấp ngưỡng CFO 500tr -> UNC 225tr -> Công nợ về 0, FCT treo TK 33318/3338), loại bỏ các phân hệ ngoài scope khỏi menu, đảm bảo 0 lỗi biên dịch và đối soát khớp 100%.

**Architecture:** Sử dụng cơ chế chuyển dịch công nợ động (Debt Transfer) tại `HoaDonGTGTDauRa` để tất toán tạm tính của `BienBanNghiemThuGiaiDoan` và chuyển toàn bộ nghĩa vụ sang Hóa đơn, cho phép `PhieuThuTienKhachHang` chọn Hóa đơn làm chứng từ gốc tất toán dứt điểm. Chuẩn hóa luồng phê duyệt AP 3 cấp với ngưỡng 500tr tính trên `TongTien` theo quy tắc không bỏ qua Kế toán trưởng. Tinh gọn giao diện Command Interface.

**Tech Stack:** 1C:Enterprise 8.3 (BSL, XML Metadata Version 2.15, Managed Application / Taxi), TT 200/2014/TT-BTC, TT 103/2014/TT-BTC, Python (verify_bsl_syntax.py).

**Spec:** Quyết định thiết kế và yêu cầu bài toán tại yêu cầu của người dùng ngày 17/10/2026.

## Global Constraints

- Không thêm tính năng ngoài phạm vi demo 2 luồng AR và AP.
- Mọi logic tính toán và kiểm tra phải là mã động theo trường dữ liệu (`TongTien`, `TyLeVAT`, `GiaTriNghiemThuChuaVAT`, `NguongCFO`), số tiền 200tr và 250tr chỉ là dữ liệu kịch bản demo (test fixtures).
- Mọi bút toán phải đảm bảo tính cân đối kép kế toán: Tổng Nợ = Tổng Có.
- Giữ nguyên các đối tượng ngoại tệ, tỷ giá, netting; chỉ cố định trong luồng demo bằng cách gán mặc định `TienTe = VND`, `TyGia = 1`, `TongTienNgoaiTe = 0` và ẩn khỏi menu giao diện.
- Người lập chứng từ cấm tự ký duyệt chứng từ của mình (Maker-Checker enforced).

  Function XacDinhTrangThaiTiepTheo(Val TrangThaiHienTai, Val TongTien = 0) Export
      TrangThaiStr = TrimAll(String(TrangThaiHienTai));

  Procedure KiemTraBuocDuyetAP(Val TrangThaiCu, Val TrangThaiMoi, Val TongTien, Val NguoiLap) Export
      If TrangThaiCu = TrangThaiMoi Then
          Return;
      EndIf;
      
      NguoiDungHienTai = UserName();
      
      // 1. CÂM Maker-Checker: Người lập không được tự duyệt bất kỳ bước nào
      If ValueIsFilled(NguoiLap) And Upper(TrimAll(NguoiLap)) = Upper(TrimAll(NguoiDungHienTai)) Then
          If TrangThaiMoi <> "DuThao" And TrangThaiMoi <> "ChoKeToanTruongDuyet" Then
              Raise "Vi phạm nguyên tắc Maker-Checker: Người lập hóa đơn không được tự duyệt các bước tiếp theo!";
          EndIf;
      EndIf;
      
      NguongCFO = Constants.NguongPheDuyetChiTienCFO.Get();
      If NguongCFO <= 0 Then
          NguongCFO = 500000000;
      EndIf;
      
      // 2. Kiểm soát bước KTT duyệt
